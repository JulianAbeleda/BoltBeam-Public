Run graph

node editor · ComfyUI / litegraph vocabulary

A run already is a DAG — load → autoscan → analyze → probe / timing → ledger → output, with typed artifacts flowing between stages. So it is drawn as one rather than as a form.

▸ Plain / Technical switch · drag nodes, drag canvas to pan, click a node to see inside — the dashed red link is evidence that was never produced
The shipped counterpart is report.html, emitted by boltbeam output from real staged artifacts. Same palette and the same accent semantics, so a colour learned in one reads the same in the other. The graph is the interactive reading of a run; the report is the portable one you can attach to a handoff.

See gui/README.md for the reasoning, and boltbeam/report/html.py for the generator.
